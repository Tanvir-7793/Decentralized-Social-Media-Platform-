# OrbitX Documentation

This folder contains course project documentation for **OrbitX** (Blockchain Technology course project).

## Folder Structure

```
documentation/
├── screenshots/   # Output screenshots from the project
│   ├── home-feed.png
│   ├── profile-page.png
│   ├── post-thread.png
│   ├── wallet-connect.png
│   └── basescan-verification.png
├── reports/       # Word documents & project reports
│   └── OrbitX_Project_Report.docx
└── diagrams/      # Architecture & workflow diagrams
```

## How to add your files

Copy your course project files from `D:\Blockchain-CourseProject\` into this folder:

1. **Screenshots** → `documentation/screenshots/`
   - Copy all files from `D:\Blockchain-CourseProject\Output Screen shots\`
   - Rename them descriptively (e.g., `home-feed.png`, `profile-page.png`)

2. **Word Document** → `documentation/reports/`
   - Copy your `.docx` file from `D:\Blockchain-CourseProject\`

3. **Diagrams** → `documentation/diagrams/`
   - Add any architecture or workflow diagrams

## Screenshot naming convention (recommended)

| File | Description |
|------|-------------|
| `home-feed.png` | Main feed view with posts |
| `profile-page.png` | User profile with handle & stats |
| `post-thread.png` | Post detail with replies |
| `wallet-connect.png` | MetaMask connection flow |
| `basescan-verification.png` | Contract on BaseScan |
